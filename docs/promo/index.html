Long description
AgentDeck - chat with the AI models you already use, from your phone.

AgentDeck is a standalone Android chat app for the providers you already have keys for. There is no backend to run and no account to create: you pick a provider, paste your API key, and your messages go straight to that provider.

It is a native Android app built with Capacitor and a React Router web UI, both this project's own MIT-licensed work. It is not the OpenHands Agent Canvas and it is not affiliated with or endorsed by All Hands AI.

First launch is two short steps: pick a provider, then paste your API key. Ollama and the custom endpoint also let you set a base URL. Then start chatting.

Why you will like it:
- Chat with OpenAI, Anthropic, Gemini, OpenRouter, Groq, DeepSeek, Mistral, xAI Grok, Ollama or a custom endpoint
- Streaming replies with a stop button, and saved conversations on the device
- Lightweight: 5.7 MB download
- Asks for internet access and nothing else
- Clean updates that install straight over the old version
- Free and open source under the MIT licence
- Works on Android 6.0 and newer

Posting notes

  • Links are not clickable in Instagram captions. Write the link as plain text, drop it in the first comment too, and add "link in bio" if you can.
  • Use the carousel, not one image. Carousels usually reach further than a single post.
  • Keep hashtags between 8 and 12. More than that reads as spam.
  • Never crop the images yourself. They are already sized and centre-safe. Cropping them again is what caused the problem before.
