01 · Overview

A thin shell around a web app. Nothing hidden.

OpenHands Agent Canvas is the web interface for OpenHands, an open-source AI software engineer. This project wraps that interface in a Capacitor shell so it installs and opens like any other Android app. You still point it at your own backend.

In short: this is the OpenHands Android app. It is a community-built mobile client for OpenHands — not an official release — and it lets you run OpenHands on your phone. It signs in to OpenHands Cloud with your Git provider, or you can point it at an agent server you run yourself. If you were looking for an OpenHands APK to sideload, this is it.

A real app, not a shortcut

It installs from an APK, appears in your launcher, and keeps its own window. No bookmark, no browser tab.

Universal build

One APK for every ABI, so it installs on any phone you have. Nothing to pick at download time.

Minimal permissions

INTERNET is the only one it asks for. No storage, no camera, no contacts, no location. Telemetry is compiled out, so the app only talks to the backend you configure.

Reproducible

The build runs in CI from the tagged source. You can rebuild it and compare the hash yourself.

Runs on old hardware

Targets Android 6.0 and up. A cheap handset from a few years back is enough to use it.

Honest about its limits

It is a client. Without your own OpenHands server running somewhere, the agent parts do nothing.

04 · Install

Four steps, about a minute.

1

Download the APK

Grab app-release.apk from the latest release. It is about 5.7 MB.

2

Allow installs from this source

Android asks once. Enable it for whichever app is doing the install, usually your browser or file manager.

3

Install and open

Play Protect may show a prompt for a sideloaded app. If you have checked the hash, choose to install anyway.

4

Connect your backend

Open the app, enter your OpenHands server URL, and start a conversation.

Updates install in place

Every build is signed with the same key, and the release is checked against it before publishing. Download a newer version and install it straight over the old one - no uninstall, no lost settings.

05 · Verify

Check the file before you trust it.

Compare the hash of the APK you downloaded with the value below. If they match, the file is byte for byte the one that was built and signed.

APK SHA-256

Printed by the build and listed on each release page — it changes with every build.

github.com/NETO-DEV66/Opanhand-mobile-/releases

Signer cert SHA-256

Fingerprint of the release signing certificate. The same for every release.

0B:05:77:B8:11:BD:3D:0E:6D:6E:F5:DA:39:07:D9:4B:91:C0:50:E6:DF:F9:7C:E1:36:0F:F5:31:40:A3:FF:47 

sha256sum app-release.apk

On macOS the same command is available as shasum -a 256 app-release.apk.

Get-FileHash .\app-release.apk -Algorithm SHA256

07 · FAQ

Common questions.

Is it safe to install?
You are installing a file from GitHub rather than the Play Store, so it is worth checking first. Compare the APK hash with the value in the Verify section, and read the source if you want. The app asks for one permission, INTERNET, and sends nothing anywhere except the backend you configure.
Why does Play Protect warn?
Play Protect flags most apps it has not seen before, including ones that are perfectly fine. It means the file was not distributed through Google, not that it is malicious. You can continue past the prompt once you have verified the hash.
Is it official?
No. This is an independent wrapper built by Sameer (@NETO-DEV66). It is not affiliated with or endorsed by the OpenHands team, and it is not the official OpenHands app. The upstream project is separate and has its own releases.
Does it work offline?
The app opens and its interface loads without a connection. Anything involving an agent needs a reachable OpenHands backend, so plan on having a network path to your server.
Do I need a Play Store account?
The app signs you in to OpenHands Cloud with GitHub, GitLab or Bitbucket — no separate password to create or remember. You sideload the APK directly. If you want update notifications without the Play Store, add the repo to Obtainium using the badge on this page.
